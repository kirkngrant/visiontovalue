# K-Sol | Google Voice Text Expansion

Status: Research / recommendation (2026-11-06)

## Problem
Find native Google Voice, external and hybrid options to insert reusable SMS replies manually.

## Recommendation
Use Espanso for free Windows-wide expansion, or Text Blaze for the simplest Edge/browser setup. Google Voice consumer messaging has no documented native saved-reply/text-expansion function. Google Voice supports manual typing and sending. Do not use consumer Voice for bulk automated messaging.

## Ranked options
1. Espanso 9.1/10 (free, configuration files)
2. Text Blaze 9.0/10 (free tier, graphical)
3. PhraseExpress 8.6/10 (GUI; personal-use licensing)
4. AutoHotkey 8.2/10 (free, scripting)
5. Clipboard templates 7.0/10 (no extra software)
6. Gmail + ChatGPT + Sheets + manual text expander 7.0/10 (contextual workflow; unconfigured)

Scores are illustrative judgments, not product ratings.
